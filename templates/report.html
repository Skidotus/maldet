How to read this report

  • This is a static scan. The code was read, never executed. Behaviour that only appears at runtime is outside what any of these detectors can see.
  • Findings are not all equally real. A classifier rates each finding on how likely it is to be genuine rather than noise, and that rating weights the scores. Measured against a hand-reviewed sample it reached precision 0.52 and recall 0.62 — useful for ranking, not a verdict on any single finding.
  • A high score is not proof of malice. Security tools, penetration-testing frameworks and malware research repositories contain the same patterns as real malware by design. The two risk types above exist to keep that distinction visible.
  • Absence of findings is not proof of safety. A detector that is not installed, or a language none of them parse, produces silence rather than a warning.
  • This scan is a snapshot. The repository may have changed since {{ repo.scanned_at.strftime('%d %B %Y') if repo.scanned_at else 'the scan date' }}.
